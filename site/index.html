// RADIO RADAR

прошивка для LilyGO T-Embed CC1101
Этот браузер не умеет прошивать по USB. Открой страницу в Chrome или Edge на компьютере. Страница должна открываться по https.
  1. Закрой программу start_pc_monitor.bat, если она запущена — она держит USB-порт палки.
  2. Подключи палку к компьютеру USB-кабелем.
  3. Нажми «Установить» и выбери в списке USB JTAG/serial debug unit.
  4. Нажми Install. Если спросят про стирание (Erase) — не ставь галочку: так сохранятся настройки палки.
  5. Дождись конца (около минуты), потом выдерни кабель и вставь обратно — палка запустится.
Адреса и файлы выбирать не нужно — кнопка сама шьёт последнюю версию по правильному адресу.
Без компьютера: на палке раздел Web → страница на телефоне → вкладка Update.
Файлы прошивки и программа для ноутбука: страница релизов.
